# Weather Forecast App

A simple weather application that displays real-time weather information for any city using the WeatherAPI service.

## 🌤 Features
- Search weather by city name
- Displays:
  - Temperature
  - Weather condition
  - Humidity
  - Weather icon
- Error message for invalid city
- Responsive UI design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript (Fetch API)

## 🔗 API Used
- Base URL: `https://api.weatherapi.com/v1/`
- Requires API Key

## 📌 Usage
1. Open index.html
2. Enter city name in the search bar
3. Click "Search"
4. Weather data will appear instantly

## 🚫 Error Handling
- Shows a message if:
  - City is not found
  - Internet connection issues
